# PHOTOBOOTH

Offline-first photobooth web app. Capture photos, frame them in templates, adjust, and print or save as JPEG — all running locally with zero network calls after install.

## Quick Start

```bash
npm install       # installs deps, vendors icons, generates frames
npm start          # builds client + starts server at http://localhost:3000
```

Open **http://localhost:3000** in your browser.

## Requirements

- **Node.js** ≥ 18.11 (for `--watch` flag in dev mode)
- **npm** ≥ 8
- A modern browser (Chrome, Edge, Firefox)

## DSLR Camera Support (Optional)

The app auto-detects DSLR cameras via CLI tools. If none is found, it falls back to the browser webcam.

### Windows
Install **digiCamControl** from [digicamcontrol.com](https://digicamcontrol.com/).
Expected install path: `C:\Program Files\digiCamControl\CameraControlCmd.exe`

### Linux
```bash
sudo apt install gphoto2
```

### macOS
```bash
brew install gphoto2
```

## Development

```bash
npm run dev     # starts Vite dev server (port 5173) + Express API (port 3001) concurrently
```

Vite proxies `/api`, `/output`, and `/frames` to Express.

## User Flow

1. **Home** → press **START SESSION** (film icon)
2. **Frame Select** → choose a built-in frame or import a custom PNG
3. **Capture** → photos are taken with an 8-second countdown (configurable) until every slot is filled
4. **Adjust** → view drafts, retake any slot, crop/pan/zoom, adjust brightness/contrast/grayscale, rotate, flip, or swap the frame
5. **Result** → print via the browser print dialog (4×6 inch page) or save as JPEG to the active folder

## Folder Management

- Click the **+** icon on the home page to create a new folder
- Output is saved to `./output/<folder>/drafts/` and `./output/<folder>/results/`
- Active folder is persisted in `config.json`

## Custom Frames

- Import any PNG with transparent rectangular regions (the app auto-detects photo slots from alpha transparency)
- Manually add, remove, or resize slots in the import dialog
- Custom frames are saved to `./frames/` alongside the built-in ones

## API Reference

| Method | Route | Description |
|--------|-------|-------------|
| `GET` | `/api/camera/status` | Detect camera type and status |
| `POST` | `/api/camera/capture` | Trigger DSLR capture |
| `POST` | `/api/camera/refresh` | Force camera re-detection |
| `GET` | `/api/config` | Read config |
| `PATCH` | `/api/config` | Update config |
| `GET` | `/api/folders` | List folders |
| `POST` | `/api/folders` | Create folder |
| `PATCH` | `/api/folders/active` | Set active folder |
| `GET` | `/api/frames` | List frames |
| `POST` | `/api/frames` | Upload custom frame |
| `PUT` | `/api/frames/:id` | Update frame metadata |
| `GET` | `/api/frames/:id/image` | Serve frame PNG |
| `GET` | `/api/drafts` | List drafts |
| `POST` | `/api/drafts` | Save draft (base64 or multipart) |
| `DELETE` | `/api/drafts/:filename` | Delete draft |
| `GET` | `/api/results` | List results |
| `POST` | `/api/results` | Compose + save final JPEG |

## Design System

Follows the **RawBlock** design system strictly:
- Black (#000) and white (#FFF) only — blue (#00F) reserved for links
- 0px border radius on ALL elements (except radio buttons = circles)
- No shadows anywhere — hierarchy via border weight (3-5px)
- Full color inversion on hover/active
- Uppercase + letter-spacing on buttons and labels
- Disabled = grey fill + #CCC border (no opacity)
- Fonts: Archivo Black (headlines), Work Sans (body), Space Mono (mono)

## Offline Guarantee

After `npm install`, the app runs fully offline:
- Fonts vendored via `@fontsource/*` packages (bundled by Vite)
- Material Icons vendored to `public/vendor/` (copied from npm)
- Zero CDN references, zero external network calls at runtime
- Server-side image compositing via `sharp` (prebuilt native binaries)
